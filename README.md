# Viva AI

    PROJETO: Api Front-end Viva Ai - Curso de Tecnico Informafica para Internet

PROBLEMA: Eventos culturais, esportivos e de lazer são divulgados em diferentes canais, o que dificulta saber o que acontecerá, quando, onde e por qual valor. O público precisa de uma agenda organizada que facilite a descoberta e a reserva simulada de vagas. 

DESCRIÇÃO: O Viva AI é uma plataforma para descoberta e reserva de eventos. O sistema permite pesquisar eventos, aplicar filtros, favoritar opções e realizar reservas de ingressos.

PÚBLICO ALVO: Nosso público-alvo são pessoas que procuram eventos para participar, como eventos sociais, culturais, esportivos, educacionais, musicais, tecnológicos e religiosos.
A ideia é atender principalmente usuários que querem encontrar eventos de maneira rápida e ter suas escolhas organizadas em um único lugar.

## Tecnologias

- HTML5
- CSS3
- JavaScript
- LocalStorage
- Font Awesome
- JSON
- API de QR Code

## Funcionalidades

- Listagem de eventos
- Pesquisa de eventos por nome
- Filtro por categoria
- Filtro por data
- Visualização dos detalhes dos eventos
- Sistema de favoritos
- Calendário de eventos
- Reserva de ingressos
- Validação da quantidade de ingressos
- Controle de vagas disponíveis
- Geração de código para a reserva
- Geração de QR Code para o ingresso
- Visualização de minhas reservas
- Cancelamento de reservas
- Persistência de favoritos e reservas utilizando `localStorage`
- Identificação de eventos lotados

## Execução

Para executar o projeto localmente:

1. Faça o download ou clone este repositório.
2. Abra a pasta do projeto no seu editor de código.
3. Execute o arquivo `inicio.html` em um navegador.

Recomenda-se utilizar uma extensão como **Live Server** no Visual Studio Code para executar o projeto corretamente.
